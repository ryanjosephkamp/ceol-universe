# The data dictionary of the CEOL Universe, v1.0

Generated by `pipeline/research/release/documents.py` from the columns module (`pipeline/research/release/columns.py`), the public projection (`pipeline/research/release/withholding.py`), and the release record (`pipeline/research/release/release_v1.0.json`). Do not edit it by hand: `make check` compares it with what the code prints.

Every row is a candidate string, never a verdict. `word` is the join key of every config, and `id` is the first 16 hexadecimal digits of the sha256 of the word, the same for the same string in every version.

## Null and NaN

- **Null means not measured by that source, never false.** In the evidence columns a single-token row holds 1 (listed), 0 (not listed), or -1 (the source is structurally blind to the row's class, as a list without hyphens is to a hyphenated string). A spaced row holds null in every evidence column and in the corpus columns, because those sources were not measured over spaced rows.
- **NaN in the features config** means the channel does not observe the string. It is a float value, not a null: no column of the features config holds a null.

## What v1.0 withholds

- **The columns of 5 lists** whose membership may not be published (see the card, section 6): `nwl2023`, `csw21`, `sowpods_legacy`, `web2`, `web2a`. Their labels are removed from `sources`, `intake_channels`, and `panel_sets`, and `panel_sets`, `panel_count`, and `provenance_class` are computed over the published panel sets alone.
- **Channel labels withheld for license reasons**, removed from `intake_channels`; a row whose every label was withheld carries `eol:channel-withheld`.
- **12 feature columns** (`docs/licenses/FEATURE_COLUMNS.md`): the 10 computed against a reference that holds a withheld list, `ocr_neighbor_hits`, `ocr_neighbor_freq_ratio`, `ocr_apostrophe_ratio`, `ocr_ligature_ratio`, `ocr_hyphen_drop_ratio`, `ocr_strip_ratio`, `ocr_hyphen_junction_ratio`, `morph_productivity_vn`, `morph_has_parse`, `segment_attested_fraction`; and the 2 of the character model, fitted on strings the withheld lists help choose, whose values pick out the strings those lists list: `orthotactic_logp_total`, `orthotactic_logp_per_char`.
- **The rows left with no public evidence** once those are withheld, and the census and audit rows whose every source label names a withheld list; the card counts them by reason.
